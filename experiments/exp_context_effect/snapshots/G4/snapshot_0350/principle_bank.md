# Principle Bank (G4) — SPLIT at position 150

**This file has been split.** The old 429-line principle_bank grew to
mix meta-cognitive rules (when to use the bank, how to transform
primitives) with piecemeal geometric knowledge. Drawers were spending
their reading budget on TR1-TR12 and missing the calligraphic form
knowledge they actually needed. Restructured B2 (position 150):

- **`principles_meta.md`** — TR1-TR12 meta-cognitive transformation
  rules. Read FIRST every cycle.
- **`joint_atlas.md`** — P/T/N/S joint conventions, welding rules,
  gap sizing, Bezier control derivation, direction assertions. Consult
  when a joint decision is uncertain.
- **`form_catalog.md`** — NEW file. Per-stroke × per-context anchor
  tuples and joint patterns from PASSing attempts. Consult when
  deciding "what should this stroke look like in THIS context."

The old sections (Standardized anchor convention, Rendering primitives,
Bezier control derivation, Compound-stroke joint convention, Sanity
assertions, Phase-1 stroke families, Diagonal-stroke pairs, 弯钩 recipe)
moved into `joint_atlas.md` and `principles_meta.md` as appropriate.
See `evolution.md` for the log.

**Drawers**: read `memory_index.md` first (as always); it points here
and to the three files above. This stub exists so that any historical
references to `principle_bank.md` still resolve.
