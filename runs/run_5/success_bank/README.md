# Success Bank — README — run_5

This is the **immutable code library** of mastered drawings.

- `INDEX.md` — queryable table of entries, with rubric scores and
  tags (component / character / 部首).
- `code/<name>.py` — drawing module, exposes `draw(t, ox=0, oy=0,
  scale=1.0)`. Module docstring at the top contains: tags,
  mastered-cycle, rubric breakdown, reuse examples.
- `visual/visual_index.png` — grid of past wins, regenerated by the
  Curator. Drawer sees this during render time.

**Single writer**: the Curator. The Drawer reads but never writes.

**Promotion gate** (run_5 strict):

1. Render the attempt PNG.
2. Render the GT PNG with `tools/make_char_gt.py`.
3. Open both in Claude vision side by side.
4. Answer: *is the attempt unambiguously the target character, with
   no plausible alternate reading?* Only "yes" promotes.
5. OCR result is logged but not sufficient on its own.
6. Calligraphy rubric must be ≥ 7/10 with no criterion at 0.
